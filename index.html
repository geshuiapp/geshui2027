用户使用说明书

从首次启动到日常使用 · 适用 v2.0.0 · 含试用 / 激活 / 换机 / 续期

📱 一、展示站说明

  1. 本仓库和 geshui2026 一样，是纯展示站，只放页面、说明书、免责声明和已脱敏截图
  2. 不含 App 内核代码、授权服务端、后台管理页或安装包，安装包只通过管理员发放
  3. 截图里的姓名、证件号、单位名称、信用代码、银行卡号和联系方式均为占位或星号
展示站不提供下载；需要安装包、激活码或续期，请联系管理员。

🛡 二、首次启动：先过免责声明

  1. 第一次打开是整屏免责声明，含 5 条要点：非官方工具、结果仅供参考、仅供个人学习、授权与设备绑定、付费与退款
  2. 可点「查看完整免责声明（12 节全文）」在浏览器看完整版
  3. 点「同意并继续」才能进入；点「不同意，退出」直接关闭应用
  4. 同意后出现约 2 秒启动页，随后按授权状态进入主界面或激活面板

🚦 三、启动后的三种状态

  • 已激活且未过期：直接进入主界面
  • 可领免费试用：进入主界面，顶部显示「🎁 免费试用中 mm:ss / 立即解锁」横幅
  • 未激活且无试用：停在激活 / 购买页，可粘贴在线激活码
试用需保持联网校验；断网超过 15 秒暂停试用，恢复联网后继续，倒计时按真实时间递减。

🔑 四、激活

  1. 把管理员发来的整段 O| 在线激活码粘贴到输入框
  2. 点「立即激活」，App 联网校验签名、设备绑定和是否已使用
  3. 激活成功后显示到期时间并自动进入主界面；同一设备再次激活新码会叠加时长
激活码与设备码绑定，一个码同一时间只服务一台设备；首次激活必须联网，成功后断网可用到本地到期日。

🔁 五、换机迁移：联系管理员

  1. 新设备：打开 App，在激活 / 购买页复制新设备码
  2. 把旧设备码、新设备码和购买邮箱发给管理员
  3. 管理员后台预检后一次性换机；新设备重新激活，原设备立即失效
V2.0 不在 App 内提供自助迁移或解绑入口；换机是改绑不是复制，本地业务数据不随授权迁移。

🏠 六、首页

  • 搜索栏：输入关键词搜索功能 / 服务
  • 温馨提示：滚动公告栏，显示税务相关提醒
  • 年度汇算专题：点击「进入专题页」查看
  • 背景图：可在「关于」页上传替换、调整热区、恢复默认

📋 七、收入纳税明细

  1. 首页点「收入纳税明细」进入，选择纳税年度与所得类型
  2. 长按「年度」两个字可设置年份范围，长按右侧年份数字可从列表里换年份（页面上没有对应按钮）
  3. 查询后顶部固定显示收入合计与已申报税额合计，下方按月列出记录卡
  4. 长按记录卡可修改、复制、删除；该年度无记录时点空状态可新增
  5. 修改表单字段较多，弹窗内可以上下滑动

👤 八、我的页面

  • 未登录：灰色头像，点击「注册 / 登录」进入登录页
  • 已登录：显示姓名、脱敏纳税人识别号、家庭成员 / 任职受雇 / 银行卡数量
  • 个人信息：姓名、识别号长按可修改；专项附加扣除从首页卡片进入，可新增备案
  • 任职受雇：长按企业卡片可修改、删除、复制
  • 关于 & 更新：版本号、意见反馈、购买 / 续期、首页背景图
登录是演示逻辑：任意手机号 / 证件号 + 任意密码 + 滑块拖到最右即可登录，不校验真实身份。

🔐 九、购买与续期

  1. 激活 / 购买页点「申请授权 / 续期」，选择套餐时长并提交购买申请
  2. 管理员核对后发放新的 O| 在线激活码
  3. 在同一台设备粘贴新码激活，授权时长会在原到期时间上叠加，不需要卸载重装
后台停用、改期或换机在恢复联网后生效；已激活用户断网期间仍按本地到期日判定。

❓ 十、常见问题

Q：第一次打开只有声明，没有主界面？
这是免责声明门，必须点「同意并继续」才能进入；点「不同意，退出」会直接关闭应用。
Q：没有激活码能不能先用？
新设备可领 15 分钟一次性试用；试用结束或已领过，需要联系管理员购买激活码。
Q：激活码提示已在其他设备使用？
V2.0 不在 App 内自助迁移；把旧设备码、新设备码和邮箱发给管理员，由后台一次性换机。
Q：试用倒计时为什么老是从 15 秒重来？
已修复：宽限时间按真实时间递减，关掉面板再打开会接着数。
Q：数据存在哪里？
业务数据只在本机；激活、试用、申请、反馈会联网传必要信息。首次激活、换码、换机到新设备会清空上一周期数据，续期不清。
Q：换手机前要准备什么？
先复制旧设备码和新设备码，联系管理员办理换机；本地业务数据不会迁移，重要内容请先截图留档。
Q：展示截图里的人是真实的吗？
不是。姓名、证件号、单位名称、信用代码、银行卡号和联系方式都是占位或星号，仅用于界面展示。
